# Keep work resumable

Use [Active work](active-work.md) for current tasks and handoffs. Use [Decisions](decisions.md) for choices actually made by the team. Keep event briefs based on [the template](../templates/event-brief.md) here, using a descriptive filename once a real event is planned.

At the start of work, read the latest records and confirm whether someone else is already working on the task. At the end, save:

- What changed and links to the resulting files.
- The actual status and last updated date.
- The owner, if known; leave unassigned when unknown.
- Any unresolved issue or missing decision.
- The next concrete action someone can take.

Do not claim that a draft has been published, a room booked, an event approved, credits issued, or a recap submitted without evidence. Link to the relevant record when available. Participant-level information belongs in the approved restricted system, not this repo.

Synchronise through Git so teammates receive the updated records. There is no automatic conflict resolution or live task ownership service.
